# Demo_App_Varnakov

Информационная система «Гостиница»: сервер REST API и настольное приложение для сотрудников гостиницы.
Работает с базой `booking_41_varnakov` из Demo_SQL_Varnakov.

| Папка | Содержимое |
|---|---|
| `01_App/1_Api` | Сервер REST API (Spring Boot): авторизация по ролям, номерной фонд и статусы, бронирование, заселение, оплата, выезд |
| `01_App/2_Client` | Настольное приложение (JavaFX), работает через API |
| `02_UserGuide` | Руководство пользователя (docx, pdf) |
| `03_MethodsDoc` | Документация на программное приложение: описание методов |

## Запуск

1. Развернуть БД по README из Demo_SQL_Varnakov. Параметры подключения — в `1_Api/src/main/resources/application.properties`.
2. Запустить конфигурацию `ApiApplication` в проекте `1_Api` (сервер на порту 8080).
3. Запустить конфигурацию `Launcher` в проекте `2_Client`.

При первом запуске создаётся администратор `admin` / `admin`, при первом входе пароль нужно сменить.
